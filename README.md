Keterangan

Berkas ".drawio" digunakan sebagai file sumber sehingga diagram masih bisa dibuka dan diedit kembali. File ".png" digunakan sebagai hasil ekspor untuk melihat hasil diagram.

Untuk Pertemuan 1, diagram masih berupa latihan penggunaan kakas dan belum menjadi model analisis final. Untuk Pertemuan 2, diagram juga masih berstatus latihan notasi UML.

Kesimpulan

Praktikum ini membantu memahami penggunaan Draw.io dalam membuat pemodelan UML. Dari Pertemuan 1 dilakukan pengenalan tools dan lingkungan praktikum, kemudian pada Pertemuan 2 mulai mempraktikkan notasi dasar UML berupa actor, use case, batas sistem, dan association.
